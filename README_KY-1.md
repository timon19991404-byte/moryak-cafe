# МОРЯК — телефонго ылайыктуу админ-панель

Бул топтомдо `index.html` — кардарлар көрө турган сайт, `admin.html` — админ-панель, `supabase-config.js` — туташуу жөндөөлөрү, `supabase_setup.sql` — маалымат базасынын коопсуздук эрежелери.

## Маанилүү коопсуздук
- `supabase-config.js` файлына **Project URL** жана **anon/publishable key** гана жазылат. `service_role` же `secret` ачкычын эч качан сайтка/GitHub'га салбаңыз.
- Supabase Authentication'да өзүңүздүн email менен админ аккаунтун түзүңүз. Катталуу барагы сайтта жок.
- Аккаунтту `moryak_admins` таблицасына кошмойунча админ панелине кире албайт.
- `supabase_setup.sql` ичиндеги RLS саясаттары менюну коомчулукка окууга гана берет; кошуу/өзгөртүү/өчүрүү жана сүрөт жүктөө админге гана уруксат.
- Сырсөздү эч кимге бербеңиз. Supabase'да MFA бар болсо күйгүзүңүз.

## 1. Supabase долбоорун түзүү
1. Телефондон https://supabase.com сайтына кирип аккаунт ачыңыз.
2. **New project** басыңыз, атын `moryak-cafe` деп койсоңуз болот. Долбоордун сырсөзүн коопсуз жерге сактаңыз.
3. Долбоор ачылгандан кийин **Project Settings → API** бөлүмүн ачыңыз. `Project URL` жана `anon` же `publishable` key керек.
4. `supabase-config.js` файлын ачып төмөнкү эки сапты өз маалыматыңыз менен алмаштырыңыз:
   - `SUPABASE_URL_HERE`
   - `SUPABASE_ANON_KEY_HERE`
   Ачкычтын атында `service_role` же `secret` деп турса, аны колдонбоңуз.

## 2. Базаны жана коопсуздук эрежелерин орнотуу
1. Supabase долбоорунда **SQL Editor → New query** ачыңыз.
2. `supabase_setup.sql` файлынын ичин толугу менен көчүрүп SQL Editor'ге чаптаңыз.
3. **Run** басыңыз. Ийгиликтүү бүткөнүн текшериңиз.

## 3. Админ аккаунтун түзүү
1. Supabase'да **Authentication → Users → Add user** (же Invite user) тандаңыз.
2. Өзүңүздүн email'ди жана күчтүү сырсөздү колдонуңуз. Аккаунт түзүлгөндөн кийин колдонуучунун UUID/ID'син көчүрүңүз.
3. SQL Editor'де төмөнкү суроону аткарыңыз. `СИЗДИН-USER-UUID` ордуна көчүргөн UUID'ни коюңуз:

```sql
insert into public.moryak_admins (user_id)
values ('СИЗДИН-USER-UUID');
```

Кошумча админдерге гана ушул таблицага өзүнчө уруксат менен кошуу керек. Бул таблицага ачык катталуу функциясын жасабаңыз.

## 4. GitHub жана Netlify'га жүктөө
1. `index.html`, `admin.html`, `supabase-config.js` жана башка сайттын мурдагы керектүү файлдарын GitHub репозиторийинин башкы деңгээлине жүктөңүз. Мурдагы `manifest.webmanifest`, иконкалар жана `service-worker.js` бар болсо сактаңыз.
2. Өзгөртүүлөрдү Commit кылыңыз. Netlify GitHub'га туташкан болсо, автоматтык deploy башталат.
3. Netlify жарыялаган сайттын дарегин ачыңыз. Админ дареги: `https://СИЗДИН-САЙТ-ДАРЕГИ/admin.html`.

## 5. Азыркы менюну базага кошуу
1. Supabase → SQL Editor бөлүмүндө `seed_menu.sql` файлын көчүрүп иштетиңиз. Бул учурдагы менюдагы тамактарды базага кошот жана аталышы бар тамакты экинчи жолу кайталабоого аракет кылат.
2. Кааласаңыз, Supabase'да **Table Editor → moryak_menu** аркылуу да тамак кошсоңуз болот. Кеминде `name`, `category`, `price`, `portion`, `description`, `tag`, `is_active` талааларын толтуруңуз. Сүрөттү админ панелинен жүктөсө болот.

## Колдонуу
1. `.../admin.html` дарегин ачыңыз.
2. Supabase'га түзгөн email жана сырсөз менен кириңиз.
3. Тамак кошуңуз, бар тамактын **Оңдоо** баскычын басып баасын өзгөртүңүз, сүрөт жүктөңүз же тамакты жашырыңыз/өчүрүңүз.
4. `index.html` Supabase базасынан активдүү менюну жүктөйт. Админ панелинде сакталган аталыш, баа, сүрөт жана сүрөттөмө кардарлардын менюсунда база ийгиликтүү туташса көрүнөт. Алгач Supabase орнотуп, SQL файлдарын иштетип, Netlify'га бардык файлдарды жүктөө керек. Төмөнкү эскертүүнү караңыз.

## Азыркы чектөө
Supabase долбоору, админ аккаунту, SQL эрежелери жана Netlify deploy кол менен бүткөрүлмөйүнчө админ панель иштебейт. Интернетке жүктөлгөнүн Netlify'дан текшериңиз. Форель салмагын кардар сайтындагы заказ формасы азыр болжолдуу киргизүүнү гана кабыл алат; кассадагы тараза менен автоматтык туташуу каралган эмес.
