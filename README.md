## Как запустить проект

Инструкция для разработчиков, которые захотят запустить проект у себя:

1. Клонируйте репозиторий: `git clone https://github.com/ваш-ник/moryak-cafe.git`
2. Перейдите в папку: `cd moryak-cafe`
3. Установите зависимости: `npm install` (или `pip install -r requirements.txt`, если это Python)
4. Запустите проект: `npm start` (или другая команда для вашего стека)

> Если проект не требует запуска локально (например, это просто статический сайт на HTML), напишите: «Проект размещён на Netlify, ссылка: [вставьте URL]».
